# Evidence ledger

`validation.json` and `unit-tests.txt` are generated by `scripts/validate.py` from tests actually run.
`mutations.json` records targeted assertion failures from `scripts/mutation_controls.py` after its
baseline tests pass. Source digests exclude `evidence/` to prevent circular hashing.

The reference tests include real Ed25519 signing/verification with fresh software-generated disposable
keys. NetHSM HTTP transport is mocked. Attestation is software-fixture evidence only.
Physical devices, PQ hardware, firmware reproduction and independent audit were not run.

`native-conformance.json` records 65 locally executed upstream native scenarios and seven
custody-integrated scenarios, parser/preimage comparisons and existing binary fingerprints.
The native emulator build provenance is explicitly limited; see `docs/LOCAL_ACCEPTANCE.md`.
`real-signature-checks.json` records actual OpenSSL ML-DSA positive and negative checks
against public test-key vectors. Neither report authenticates production chain state.

RFC 0005 adds `state-proof-checks.json`: native verification of genuine historical
PQ account proofs and wrong anchor/account/full-target/code/carrier controls.
The fixture account is an elector, not a live custody deployment. Synthetic unit
proof doubles are kept separate. The current native-conformance report also
records a fresh pinned-source native build and three lifecycle/pauser probes.
`setup-attempts.json` fingerprints initial failed/setup transcripts and records
why those attempts were not counted as passing evidence.

Do not edit a result into a pass. Regenerate it from the documented command. A result is not a
production approval, a third-party review, a remote GitHub CI result or a funding authorization.

RFC 0003 adds REF-level PQ highload inspection. Frozen fixture hashes were independently
reproduced with the pinned upstream Python codec; this is not native VM or signature evidence.
`reproducibility.json` records source archive comparison, not firmware reproducibility.

RFC 0004 adds cold multisig reference inspection and full-limit structural comparisons.
Reproduce `fixtures/pq-multisig-vectors.json` with the whole-blob-pinned upstream codec
using `scripts/check_upstream_multisig.py`. Frozen vectors are not independent native
execution. Quorum comparison is NOT cryptographic quorum verification. No state proof,
physical hardware or independent security review is claimed.
